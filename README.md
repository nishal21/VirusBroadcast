# VirusBroadcast


A Java-based simulation program. Due to the rushed launch and insufficient data, the model and simulation process are overly simplified. If you have good ideas or can provide relevant data support, please submit an issue.

If you are also a Java programmer, you can directly modify the code and submit a pull request to me. I have already started daily collection of epidemic data, and I hope that after the epidemic ends, there will be an opportunity to use this precise data to do a thorough review.

2020.2.6: The virus mutation process is a constant adaptation process. You can try to use a simple DNN (Deep Neural Network) to model the virus, and I have already begun implementing this.

2020.4.2: The amount of data is too small, so the simulation results are unreliable. The DNN work is temporarily suspended.
